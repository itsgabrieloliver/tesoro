# Welcome to your vault

This is a **tesoro** demo vault. tesoro is an _Obsidian-compatible_ note-taking TUI: your notes stay plain markdown files.

Things to try:

- Open [[Ideas]] and read it
- Open the [[Daily]] note
- Follow a link that does not exist yet: [[Someday]]
- Notice tags like #demo and #getting-started

> Edit any note in your `$EDITOR` and tesoro reloads it.

Inline `code` and fenced blocks render too:

```
teso ~/notes
```
